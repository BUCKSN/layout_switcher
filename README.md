# Layout Switcher for macOS (Automator Edition)

Скрипт автоматического исправления текста, набранного не в той раскладке (EN ⇄ RU). Интегрируется в систему macOS как «Быстрое действие» (Quick Action) и работает в любом приложении по горячим клавишам.

## 🚀 Возможности
* Исправление текста «на лету» в любом месте системы.
* Автоматическая замена выделенного текста.
* Конвертация в обе стороны (например, `ghbdtn` ⇄ `привет`).

## 🛠 Пошаговая установка через Automator

### Шаг 1. Создание Быстрого действия
1. Откройте программу **Automator** на вашем Mac (через Spotlight или из папки *Программы*).
2. В появившемся окне выберите тип документа: **«Быстрое действие»** (Quick Action / Служба).
3. В самом верху панели настроек установите параметры:
   * Данная служба получает: **текст**
   * в: **любой программе**
   * Галочка **«Заменить выделенный текст»** — **ОБЯЗАТЕЛЬНО ПОСТАВИТЬ**.

### Шаг 2. Добавление скрипта
1. В левой колонке найдите действие **«Запустить shell-скрипт»** (Run Shell Script) и перетащите его в правую рабочую область.
2. В настройках действия укажите:
   * Shell: `/bin/bash` (или `/bin/zsh`)
   * Передавать ввод: **как аргументы** (to stdin)
3. Полностью удалите стандартный текст из текстового поля действия и вставьте следующий код:

```python
#!/usr/bin/env python3
import sys

m_en = {
    "q": "й", "w": "ц", "e": "у", "r": "к", "t": "е", "y": "н", "u": "г", "i": "ш", "o": "щ", "p": "з",
    "[": "х", "]": "ъ", "a": "ф", "s": "ы", "d": "в", "f": "а", "g": "п", "h": "р", "j": "о", "k": "л",
    "l": "д", ";": "ж", "'": "э", "z": "я", "x": "ч", "c": "с", "v": "м", "b": "и", "n": "т", "m": "ь",
    ",": "б", ".": "ю", "/": ".", "`": "ё", "~": "Ё", "!": "!", "@": '"', "#": "№", "\$": ";", "^": ":",
    "&": "?", "*": "*", "|": "/",
    "Q": "Й", "W": "Ц", "E": "У", "R": "К", "T": "Е", "Y": "Н", "U": "Г", "I": "Ш", "O": "Щ", "P": "З",
    "{": "Х", "}": "Ъ", "A": "Ф", "S": "Ы", "D": "В", "F": "А", "G": "П", "H": "Р", "J": "О", "K": "Л",
    "L": "Д", ":": "Ж", '"': "Э", "Z": "Я", "X": "Ч", "C": "С", "V": "М", "B": "И", "N": "Т", "M": "Ь",
    "<": "Б", ">": "Ю", "?": ","
}

m_ru = {v: k for k, v in m_en.items()}

def convert_text(text):
    result = []
    for char in text:
        if char in m_en:
            result.append(m_en[char])
        elif char in m_ru:
            result.append(m_ru[char])
        else:
            result.append(char)
    return "".join(result)

if __name__ == "__main__":
    input_text = sys.stdin.read()
    sys.stdout.write(convert_text(input_text))
```

4. Нажмите `Cmd + S` и сохраните действие под понятным именем, например: `Fix Layout`.

---

### Шаг 3. Настройка горячих клавиш
1. Перейдите в **Системные настройки** macOS ➔ **Клавиатура** ➔ **Сочетания клавиш** (Keyboard Shortcuts).
2. В левом меню выберите **Службы** (Services) или **Быстрые действия**.
3. В разделе *Текст* найдите созданную службу `Fix Layout`.
4. Нажмите дважды справа от названия службы и задайте удобное сочетание клавиш (например, `Ctrl + Cmd + X`).

## 💻 Использование
1. Выделите текст, набранный не в той раскладке (например, `ghbdtn`).
2. Нажмите ваше сочетание клавиш.
3. Текст автоматически заменится на корректный (`привет`).
